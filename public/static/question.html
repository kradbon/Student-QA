Почему асинхронная функция возвращает Promise?

javascriptasync/await

Разбираюсь с async/await в JavaScript. Почему результат функции нужно получать через await? Я ожидал, что функция вернёт готовое значение, но в консоли вижу объект Promise.

Подскажите, пожалуйста, как правильно получить результат и обработать возможную ошибку. Пример:

async function loadUser() {
  return fetch('/api/user');
}

Ответы 3

✓ Принятый ответ

Функция, объявленная с ключевым словом async, всегда возвращает Promise. Это позволяет использовать await внутри функции и удобно обрабатывать завершение асинхронной операции.

Чтобы получить значение, дождитесь результата: const response = await loadUser();. Ошибки можно перехватить блоком try/catch.

Ещё можно вызвать .then() у возвращаемого Promise. Оба варианта подходят, но await часто читается проще, если операций несколько.
