# Лабораторияи 11 — интерактивии frontend

Ин татбиқ ба Student Q&A Platform мутобиқ карда шудааст. JavaScript-и ванилӣ ҳамчун ES-модул истифода мешавад; барои интерфейс React/Vue лозим нест.

## Файлҳо

- [`public/assets/js/app.js`](../../public/assets/js/app.js) — ҷустуҷӯи фаврӣ, санҷиши шакли савол ва тасдиқи ҳазф.
- [`public/api/questions/index.php`](../../public/api/questions/index.php) — API-и муваққатӣ бо 6 савол. Сабти охирин HTML дорад, то намоиши бехатар санҷида шавад.
- [`public/static/questions.html`](../../public/static/questions.html) — рӯйхати саволҳо, GET-search ва шакли эҷоди савол.
- [`public/static/question.html`](../../public/static/question.html) — саҳифаи савол ва равзанаи тасдиқи ҳазф.
- Ҳар се саҳифаи статикӣ `app.js`-ро бо `type="module"` пайваст мекунанд.

## Рафтор

1. **Беҳсозии тадриҷӣ:** бе JavaScript шакли ҷустуҷӯ GET мефиристад ва шакли савол тавассути POST кор мекунад. JavaScript ҷустуҷӯро бе навсозии саҳифа иҷро мекунад.
2. **Валидатсия:** сарлавҳа бояд ҳадди ақал 15 аломат ва тавсиф ҳадди ақал 30 аломат дошта бошад. `setCustomValidity()` қоидаҳои махсусро муқаррар мекунад; паёмҳои тоҷикӣ бо `aria-describedby` пайвастанд ва фокус ба майдони аввали хато мегузарад.
3. **Ҷустуҷӯ:** `fetch` + `async/await`, `debounce` 300 мс ва `AbortController`; ҳолатҳои боркунӣ, натиҷаи холӣ ва хато бо `aria-live` эълон мешаванд.
4. **Амнияти барориш:** унсурҳо бо `createElement` сохта шуда, маълумот танҳо ба `textContent` дода мешавад. API як сарлавҳаи дорои `<img onerror>` дорад; он ҳамчун матн мемонад ва унсури `img` сохта намешавад.
5. **Ҳазф:** як коркардкунандаи `click` дар `document` тугмаи `data-delete-url`-ро муайян мекунад. Bootstrap Modal амалро тасдиқ мекунад ва ҳангоми пӯшидан фокус ба тугмаи оғозкунанда бармегардад.

## Оғоз ва санҷиш

Аз решаи репозиторий серверро оғоз кунед:

```sh
php -S 127.0.0.1:8000 -t public
```

Саҳифаро дар `http://127.0.0.1:8000/static/questions.html` кушоед. Дар ҷустуҷӯ `HTML` нависед: сабти санҷишӣ бояд ҳамчун матн нишон дода шавад. Шаклро бо сарлавҳаи кӯтоҳ фиристед: паёми тоҷикӣ пайдо шуда, фокус ба сарлавҳа мегузарад. Дар саҳифаи савол «Удалить вопрос»-ро пахш карда, равзана ва бозгашти фокусро санҷед. Санҷиши браузер барои ҷустуҷӯи бехатар, паёмҳои шакл ва фокус, инчунин равзанаи тасдиқ иҷро шудааст; `node --check public/assets/js/app.js` ва `php -l public/api/questions/index.php` муваффақ шуданд.
