## 2. Мақсадҳо ва таъиноти сохтани система

### 2.1. Таъиноти система

Система барои ташкили муҳити ягонаи мубодилаи дониш байни донишҷӯён пешбинӣ шудааст.

Донишҷӯ метавонад савол нашр кунад, ба саволҳои дигарон ҷавоб диҳад, ҷавобҳоро баҳогузорӣ кунад ва барои саволи худ ҷавоби беҳтаринро интихоб намояд.

Модератор сифати мундариҷаро назорат мекунад. Администратор корбарон, нақшҳо, категорияҳо ва тегҳоро идора мекунад.

Корбарони система:
1. Student;
2. Moderator;
3. Admin.

### 2.2. Мақсадҳои ченшаванда

| Рамз | Мақсад | Нишондиҳандаи қабул |
|---|---|---|
| G-01 | Содда кардани ҷустуҷӯи савол | Ҷустуҷӯ дар базаи 10 000 савол барои 95% дархостҳо дар ≤1 сония |
| G-02 | Содда кардани нашри савол | Эҷоди савол дар на бештар аз 3 қадам |
| G-03 | Таъмини мубодилаи дониш | Донишҷӯ метавонад савол ва ҷавоб нашр кунад |
| G-04 | Назорати мундариҷа | Модератор метавонад саволро тасдиқ ё рад кунад |
| G-05 | Назорати фаъолияти ҷомеа | Ҳисоб кардани шумораи саволҳо ва ҷавобҳо аз рӯи категория |

## 3. Тавсифи объекти автоматикунонӣ

### 3.1. Равандҳои мавҷуда

Дар ҳолати дастӣ донишҷӯён саволҳоро дар гурӯҳҳои паёмрасон, шабакаҳои иҷтимоӣ ё ҳангоми дарс пешниҳод мекунанд.

Ҷавобҳо дар ҷойҳои гуногун паҳн мешаванд. Ҷустуҷӯи ҷавоби қаблӣ душвор буда, таърихи овоздиҳӣ ва муайян кардани ҷавоби беҳтарин мутамарказ нест.

### 3.2. Иштирокчиёни раванд

| Иштирокчӣ | Вазифаҳо | Объектҳои дода |
|---|---|---|
| Student | Сабти ном, нашри савол, ҷавоб, овоздиҳӣ | users, questions, answers, votes |
| Moderator | Санҷиш, тасдиқ, рад ва пӯшидани муҳокима | questions, moderation_logs |
| Admin | Идоракунии корбарон, нақшҳо ва категорияҳо | users, categories, tags |

### 3.3. Объектҳои асосии иттилоотӣ

Система маълумоти зеринро нигоҳ медорад:
- корбарон;
- категорияҳо;
- саволҳо;
- ҷавобҳо;
- ҷавобҳои беҳтарин;
- тегҳо;
- овозҳо;
- таърихи обрӯ;
- файлҳои замимашуда;
- огоҳиномаҳо;
- журналҳои модератсия.

### 3.4. Мушкилоти ҳалшаванда

- Пароканда будани саволу ҷавобҳо.
- Такрор шудани саволҳои якхела.
- Набудани ҷустуҷӯи ягона.
- Душвории муайян кардани ҷавоби муфид.
- Набудани таърихи овоздиҳӣ.
- Набудани механизми марказии модератсия.

### 3.5. Ҳудуди система

Система платформаи саволу ҷавоб мебошад. Он LMS-и пурра, видеоконфронс, пардохт ва идоракунии музди меҳнатро дар бар намегирад.

## 4. Талабот ба низоми автоматикунонидашуда

### 4.1. Талабот ба система дар маҷмӯъ

#### 4.1.1. Сохтор ва реҷаҳои кор

Система аз модулҳои зерин иборат аст:

1. Бақайдгирӣ ва аутентификатсия.
2. Профили корбар ва нақшҳо.
3. Саволҳо ва категорияҳо.
4. Ҷавобҳо.
5. Овоздиҳӣ ва обрӯ.
6. Тегҳо ва замимаҳо.
7. Огоҳиномаҳо.
8. Модератсия.
9. Ҳисобот ва содироти CSV.

Система бояд 24 соат дар як рӯз ва 7 рӯз дар як ҳафта дастрас бошад, ба истиснои корҳои банақшагирифтаи хизматрасонӣ.

Меъморӣ вебӣ ва муштарӣ-серверӣ мебошад. Браузер тавассути HTTPS ба веб-сервер муроҷиат мекунад. Қисми серверӣ бо PHP/Laravel кор карда, ба MySQL пайваст мешавад.

Диаграммаҳои меъморӣ ва ҷойгиркунӣ дар ҳуҷҷатҳои `docs/05-structure/` ва `docs/07-deployment.puml` ҷойгир карда мешаванд.

#### 4.1.2. Шумора ва тахассуси корбарон

Система бояд дастгирӣ кунад:
- то 1 000 ҳисоби сабтшуда;
- то 50 корбари ҳамзамон;
- то 10 000 савол;
- то 100 000 ҷавоб ва овоз.

Барои Student ва Moderator малакаи кор бо браузер кифоя аст. Admin бояд малакаи асосии идоракунии система дошта бошад.

#### 4.2.1. Қоидаҳои бизнес

1. Танҳо Student метавонад савол ва ҷавоб эҷод кунад.
2. Танҳо муаллифи савол метавонад ҷавоби беҳтаринро интихоб кунад.
3. Барои як савол танҳо як ҷавоби беҳтарин иҷозат дода мешавад.
4. Корбар наметавонад ба ҷавоби худаш овоз диҳад.
5. Барои як ҷуфти voter ва answer танҳо як овози фаъол нигоҳ дошта мешавад.
6. Ҷавоб бояд ба саволи мавҷуда тааллуқ дошта бошад.
7. Саволи радшуда дар рӯйхати оммавӣ нишон дода намешавад.
8. Амалҳои модератор дар moderation_logs сабт мешаванд.
9. Нақшҳои система танҳо student, moderator ва admin мебошанд.
10. Як ҳодисаи интихоби ҷавоби беҳтарин набояд ду маротиба хол диҳад.

## 6. Тартиби коркарди система

1. Коди сарчашма дар Git нигоҳ дошта мешавад.
2. Марҳилаҳо бо тегҳои day-01 то day-16 қайд карда мешаванд.
3. Commit message бо шаклҳои `feat:`, `fix:`, `docs:`, `test:` навишта мешавад.
4. Тағйироти база тавассути migration ё `database/schema.sql` сабт карда мешаванд.
5. Файлҳои `.env`, паролҳо ва калидҳои махфӣ ба Git илова карда намешаванд.
6. Тағйироти муҳим пеш аз муттаҳидкунӣ санҷида мешаванд.
7. Ҳар талаботи FR/NFR бояд усули санҷиши муайян дошта бошад.

## 7. Тартиби назорат ва қабули система

### 7.1. Намудҳои санҷиш

- Санҷиши модулӣ: валидатсия, овоздиҳӣ, интихоби ҷавоби беҳтарин ва ҳисобкунии обрӯ.
- Санҷиши интегратсионӣ: Laravel бо MySQL, саволҳо, ҷавобҳо ва огоҳиномаҳо.
- Санҷиши амният: иҷозатҳои нақшҳо, CSRF, SQL injection, XSS ва upload.
- Санҷиши қабулӣ: санҷиши сенарияҳои корбар аз рӯи FR ва NFR.

### 7.2. Меъёрҳои қабул

Система қабулшуда ҳисобида мешавад, агар:
1. ҳамаи талаботи Must иҷро шуда бошанд;
2. се нақш танҳо амалҳои иҷозатдодашударо иҷро кунанд;
3. савол, ҷавоб, овоз ва ҷавоби беҳтарин дуруст нигоҳ дошта шаванд;
4. овоздиҳии такрорӣ ва овоз ба ҷавоби худ манъ карда шавад;
5. модератсия сабаби қарорро сабт кунад;
6. schema.sql ва seed.sql дар базаи холӣ бе хато иҷро шаванд;
7. санҷишҳои асосии амниятӣ гузаранд;
8. ҳуҷҷатҳои супоришӣ пешниҳод шаванд;
9. хатои кушодаи сатҳи Critical ё High боқӣ намонад.

### 7.3. Ҳуҷҷати тасдиқи қабул

Натиҷаи санҷиш дар `docs/15-test-cases.md` сабт мешавад. Барои лоиҳаи таълимӣ тасдиқи ниҳоӣ тавассути намоиши система ва ҳимоя иҷро мегардад.
