# Матритсаи муқоисавии аналогҳо: Student Q&A Platform

**Донишҷӯ:** маълумоти шахсӣ дар файлҳои repository муайян нашудааст  
**Мавзӯи лоиҳа:** Платформаи саволу ҷавоби донишҷӯён, Вариант 24  
**Санаи омодасозӣ:** 15.11.2026

## Ҳадафи муқоиса

Омӯхтани системаҳои саволу ҷавоб ва муҳокимаи таълимӣ, муқоисаи имкониятҳои асосӣ ва муайян кардани талаботи мувофиқ ба Student Q&A Platform. Стек аз лоиҳаи воқеӣ гирифта шудааст: PHP ^8.3, Laravel ^13.17, Blade, Vite ва Tailwind CSS; MySQL дар SQL/deployment пешбинӣ шудааст, дар ҳоле ки Feature tests SQLite in-memory истифода мебаранд.

## 1. Меъёрҳои муқоиса

Меъёрҳо пеш аз ҷамъбасти аналогҳо аз талаботи лоиҳа интихоб шудаанд. K1–K5 функсионалӣ, K6–K8 сифат/ҷойгиркунӣ мебошанд; K9 иҷроишро танҳо баъд аз ченкунӣ арзёбӣ мекунад.

| № | Меъёр | Шкалаи арзёбӣ | Вазн |
|---|---|---|---:|
| K1 | Савол, ҷавоб ва ҷавоби қабулшуда | 0 — нест; 1 — танҳо саволу ҷавоб; 2 — ҷавоб ва интихоби ҷавоби беҳтарин | 2 |
| K2 | Ҷустуҷӯ ва гурӯҳбандӣ | 0 — нест; 1 — филтри сода; 2 — ҷустуҷӯ ва category/topic | 2 |
| K3 | Vote ва обрӯи иштирокчӣ | 0 — нест; 1 — танҳо реаксия/баҳогузорӣ; 2 — vote ва reputation | 2 |
| K4 | Moderation ва report | 0 — нест; 1 — идоракунии одӣ; 2 — review/report/history | 2 |
| K5 | Дастгирии муҳити таълимӣ | 0 — умумӣ; 1 — метавон мутобиқ кард; 2 — Q&A-и курсӣ | 2 |
| K6 | Забон ва дастрасӣ | 0 — маҳдуд; 1 — интерфейси чандзабона ё адаптивӣ; 2 — ҳар ду тасдиқ шудаанд | 1 |
| K7 | Замима ва огоҳинома | 0 — нест; 1 — яке аз онҳо; 2 — ҳар ду | 1 |

Максимум барои K1–K8: 2 × (2+2+2+2+2+1+1+2) = **28 хол**. K9 ба натиҷаи умумӣ дохил намешавад, то ченкунии яксон анҷом ёбад.

## 2. Аналогҳо

| Аналог | Навъ | Манбаи расмӣ |
|---|---|---|
| Stack Overflow | Саволу ҷавоби оммавӣ барои масъалаҳои техникӣ | https://stackoverflow.com/tour |
| Piazza | Муҳокима ва саволу ҷавоби курсӣ | https://piazza.com/help/faq/ |
| Moodle Forum | Форуми дохили LMS-и таълимӣ | https://docs.moodle.org/en/Forum_activity |
| Discourse | Платформаи муҳокима ва ҷомеаи онлайн | https://www.discourse.org/features |

Stack Overflow ҳамчун формати Q&A бо moderation-и ҷомеа муаррифӣ мешавад. Piazza ба Q&A-и курсӣ нигаронида шудааст. Moodle Forum фаъолияти форумро дар дохили LMS таъмин мекунад. Discourse бештар муҳокима, идоракунии ҷомеа ва moderation-ро муттаҳид мекунад. Хусусият/тариф метавонад тағйир ёбад; истинодҳо бояд пеш аз супоридани ниҳоӣ аз нав санҷида шаванд.

## 3. Матритсаи муқоиса

**Эзоҳи муҳим:** баллҳои зер арзёбии муқаддамотии функсияҳо аз саҳифаҳои расмии оммавӣ мебошанд, на натиҷаи санҷиши ҳамаи версияҳо ё тарифҳо. «Н/Д» маънои онро дорад, ки аз манбаи санҷидашуда далели кофӣ гирифта нашуд. Натиҷаи Variant 24 дар сутуни ҳадаф талаботи лоиҳа аст, на даъвои он ки ҳар хусусият аллакай татбиқ шудааст.

|---|---|---|---|---|---|

## 4. Баррасии таъсири муқоиса ба тарҳ

Тарҳи лоиҳа аз ин хусусиятҳо истифода мебарад: ҷудо кардани question ва answer; accepted answer; vote/reputation; ҷустуҷӯ ва category; moderation/report; notification ва download-и иҷозатсанҷидашуда. Интихобҳо бо domain-и донишҷӯӣ мувофиқанд.

Тафовутҳо ва қарорҳо:

- **K1/K3:** модели савол–ҷавоб ва reward-и accepted answer аз Q&A гирифта мешавад. Laravel ин ҷараёнро дорад.
- **K4:** навбат ва log-и moderation барои муҳтавои донишҷӯӣ муҳим аст; route/service дар лоиҳа мавҷуд аст.
- **K5:** Piazza/Moodle нишон медиҳанд, ки контексти курсӣ муҳим аст; Variant 24 категория дорад, вале enrollment-и LMS надорад.
- **K6:** Laravel locale-и tj/ru/en дорад. Adaptive usability бояд дар браузер санҷида шавад.
- **K7:** замима ва notification бояд private/authorization санҷиш дошта бошанд.
- **K8:** deployment diagram self-hosted Nginx/PHP-FPM/MySQL-ро нишон медиҳад; сервери воқеӣ ҳанӯз санҷида нашудааст.
- Tag-и M:N дар SQL-и Lab 6 тасвир шудааст, аммо migration-и Laravel онро намесозад; ин gap аст, на хусусияти анҷомшуда.

## 6. Санҷиши PageSpeed

Меъёри K9 то дастрас шудани муҳити оммавии муқоисашаванда хол намегирад. Барои анҷом:

1. Версияи якхелаи веб/саҳифаи оммавӣ интихоб кунед.

3. Барои ҳар натиҷа URL, сана, Performance Score ва скриншот сабт кунед.
