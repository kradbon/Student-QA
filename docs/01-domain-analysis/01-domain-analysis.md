# Таҳлили предметной области: Student Q&A Platform — платформаи саволу ҷавоби донишҷӯён

## 1. Муассиса ва муҳити лоиҳа

Предметная область — мубодилаи донишҳои таълимӣ байни донишҷӯён. Student саволи фаннӣ ё таълимӣ нашр мекунад; донишҷӯёни дигар ҷавоб медиҳанд; муаллифи савол ҷавоби муфидро интихоб карда метавонад. Барои нигоҳ доштани сифати муҳтаво Moderator савол ва гузоришҳоро баррасӣ мекунад. Admin корбарон, категорияҳо ва танзимоти платформаро идора менамояд.

Дар ҳолати ҷорӣ чунин ҳамкорӣ метавонад дар чат, почтаи электронӣ ё ҳуҷҷатҳои ҷудогона сурат гирад. Замимаи вебӣ савол, ҷавоб, овоз, категория, замима ва таърихи moderation-ро дар муҳити ягона нигоҳ доштанӣ аст. Муассиса ё фармоишгари мушаххас дар repository муайян нашудааст; тавсиф модели таълимии предметная область мебошад.

### Мушкилоти раванди ҷорӣ

1. Саволу ҷавобҳо дар каналҳои ҷудогона мемонанд ва ҷустуҷӯи ҷавоби қаблӣ душвор мешавад.
2. Ҷавоби муфид байни ҷавобҳои дигар муайян нест, агар қабули беҳтарин ё овоздиҳӣ набошад.
3. Саволи номувофиқ ё такрорӣ бе навбати баррасӣ ва таърихи moderator метавонад сари вақт коркард нашавад.
4. Замима ва notification дар канали алоҳида гум шуда метавонанд.
5. Ҳисоботи фаъолият ва обрӯи иштирокчиён дастӣ ҷамъ карда мешавад.

*Эзоҳ: мушкилоти мазкур аз таҳлили модели лоиҳа бармеоянд; дар repository ченкунии кори ташкилоти мушаххас вуҷуд надорад.*

## 2. Акторҳо

| Роль | Шахс/гурӯҳ | Амал дар система |
|---|---|---|
| student | Донишҷӯи сабтиномшуда | Савол месозад ва идора мекунад, ба саволи дигарон ҷавоб медиҳад, овоз медиҳад, профилро нав мекунад ва ҷавоби саволи худашро қабул мекунад. |
| moderator | Модератори мундариҷа | Саволҳои нав, гузоришҳо ва мундариҷаро баррасӣ мекунад; таърихи амалҳоро мебинад ва амалҳои иҷозатдодашудаи account-ро иҷро мекунад. |
| admin | Маъмури платформа | Корбар, role/status, категория, танзим ва ҳисоботи CSV-ро идора мекунад; ба баъзе route-ҳои moderation низ дастрасӣ дорад. |
| Guest | Меҳмони бе ҳисоби воридшуда | Саволҳои умумиро мебинад, меҷӯяд ва ба сабти ном/воридшавӣ мегузарад. Guest role-и сабтшуда дар users нест. |

Дар коди Laravel role-ҳои захирашаванда student, moderator ва admin мебошанд. Guest актори беруна аст. Role ба ҳисоб вобаста буда, тавсифи умумии он дар routes/web.php, RequireRole ва User::isRole() дида мешавад.

## 3. Бизнес-процессҳо

| Раванд | Иштирокчиён | Оғоз | Натиҷа |
|---|---|---|---|
| Сабт ва воридшавӣ | Guest | Корбар мехоҳад иштирок кунад | Ҳисоби student ва session-и authenticated сохта мешавад. |
| Эҷод ва баррасии савол | Student, Moderator | Донишҷӯ масъалаи таълимӣ дорад | Савол pending мешавад; пас аз approve нашр, ё reject шуда ба муаллиф бармегардад. |
| Ҷавоб додан | Student | Саволи published кушода аст | Ҷавоб ба савол ва муаллиф пайваст шуда, муаллифи савол notification мегирад. |
| Овоз ва обрӯ | Student, система | Иштирокчӣ ҷавобро арзёбӣ мекунад | Овоз ва тағйири reputation ба қайд гирифта мешавад. |
| Интихоби ҷавоби беҳтарин | Муаллифи савол, система | Барои савол ҷавоби мувофиқ мавҷуд аст | Ҷавоб accepted мешавад ва муаллифи он хол мегирад. |
| Ҳисобот ва идораи платформа | Student, Moderator, Admin | Мундариҷа гузориш ё танзим лозим мешавад | Moderator report-ро мебинад; Admin category, user, settings ё CSV-ро идора мекунад. |

### 3.1. Ҷараёни савол аз фиристодан то ҷавоби беҳтарин

**Иштирокчиён:** student, moderator ва дигар донишҷӯён.

**Оғоз:** донишҷӯ ба шарҳи мавзӯъ ё ҳалли масъала эҳтиёҷ дорад.

1. Student ба шакли савол мегузарад, title, body ва category-и фаъолро интихоб мекунад.
2. Система маълумот ва маҳдудияти замимаро месанҷад.
3. Савол дар ҳолати pending сабт мешавад; агар замима бошад, он дар disk-и хусусӣ нигоҳ дошта мешавад.
4. Moderator саволро дар навбат мебинад ва approve ё reject мекунад.
5. Агар савол нашр шавад, дигар донишҷӯён онро меёбанд ва ҷавоб мефиристанд.
6. Муаллифи савол ҷавобҳоро мехонад; метавонад овоз диҳад ва як ҷавобро қабул кунад.
7. ReputationService сабти холро бо event key нигоҳ медорад; ба ҷавобдиҳанда notification фиристода мешавад.
8. Агар саволро пӯшанд, он хоногӣ мемонад ва ҷавобдиҳии нав маҳдуд мешавад.

**Натиҷа:** савол, ҷавоб, ҳолати moderation, овозҳо ва натиҷаи accepted answer дар замима сабт мешаванд. Ин ҷараён дар коди Laravel татбиқ шудааст; вижагиҳои tags мустақил дар базаи runtime татбиқ нашудаанд.

## 4. Объектҳои додаҳо

Ин ҷадвал schema-и амалкунандаи Laravel migration-ро инъикос мекунад. Дар бахши алоҳидаи SQL баъзе номи ҷадвалҳо/сутунҳо дигар аст; фарқиятро дар тасвири runtime бояд ба ҳисоб гирифт.

| Объект | Маълумоти асосӣ ва робита |
|---|---|
| Корбар (users) | name, email, password, role, status, reputation, locale ва avatar_path. |
| Категория (categories) | name, slug, description ва is_active; категория метавонад бисёр савол дошта бошад. |
| Савол (questions) | user_id, category_id, title, body, status, views ва accepted_answer_id. |
| Ҷавоб (answers) | question_id, user_id, body ва status; савол метавонад бисёр ҷавоб дошта бошад. |
| Овоз (votes) | user_id, votable_type, votable_id ва value; муносибати polymorphic ба question ё answer. |
| Амали обрӯ (reputation_transactions) | user_id, actor_id, event_key, reason, points ва source polymorphic. |
| Замима (question_attachments, answer_attachments) | Ба савол ё ҷавоб, uploader, path, mime_type ва size вобаста аст. |
| Гузориш (reports) | user_id, reportable_type/id, reason, status ва reviewed_by. |
| Таърихи moderation (moderation_logs) | moderator_id, moderatable_type/id, action ва note. |
| Огоҳинома (notifications) | UUID, type, notifiable_type/id, data ва read_at. |
| Танзим (platform_settings) | key/value барои танзими платформа. |
| Tag | Дар SQL-и алоҳидаи Lab 6 tags ва question_tags ҳастанд, аммо migration-и ҳозираи Laravel онҳоро намесозад; хусусияти мустақил нақшавӣ мемонад. |

Ҷадвалҳои accepted_answers ва attachments дар SQL-и алоҳида ҳастанд, аммо Laravel runtime ба ҷои онҳо accepted_answer_id, question_attachments ва answer_attachments-ро истифода мебарад.

## 5. Луғати истилоҳот

| Истилоҳ | Маъно |
|---|---|
| Савол (Question) | Мавзӯи таълимии нашршаванда бо category, муаллиф ва status. |
| Ҷавоб (Answer) | Шарҳи донишҷӯ ба саволи нашршуда. |
| Ҷавоби қабулшуда | Ҷавобе, ки муаллифи савол интихоб кардааст. |

| Tag | Калимаи тамға барои гурӯҳбандии чандир; persistence-и ҷорӣ татбиқ нашудааст. |
| Овоз (Vote) | Арзёбии мусбат ё манфии савол/ҷавоб. |
| Reputation | Нишондиҳандаи саҳми корбар, ки тавассути транзаксияҳо нав мешавад. |
| Гузориш (Report) | Дархости баррасии мундариҷаи номувофиқ аз ҷониби корбар. |
| Moderation | Баррасӣ ва идораи мундариҷа аз ҷониби moderator/admin. |
| Замима | Файле, ки ба савол ё ҷавоб пайваст ва бо иҷозат зеркашӣ мешавад. |

## 6. Манбаъҳои талабот

Барои таҳлили таълимӣ ин манбаъҳо истифода мешаванд:

1. **Таҳлили супориши лоиҳа ва код.** Аз README, route, model, controller, migration ва санҷишҳои мавҷуда нақшҳо ва workflow муайян мешаванд.
2. **Таҳлили ҳуҷҷатҳои қаблӣ.** Диаграммаҳои Use Case/Activity ва ER дар docs/04, docs/06 барои фаҳмидани мақсади Labs истифода мешаванд; фарқияти онҳо аз code сабт мегардад.
3. **Мусоҳибаи сохторёфта бо донишҷӯ ва moderator.** Барои тасдиқи қоидаи саволи такрорӣ, сабаби reject, мӯҳлати нигоҳдории report ва раванди идораи tag пешниҳод мешавад. Ин мусоҳиба ҳоло гузаронида нашудааст.

### Саволҳо барои мусоҳиба

1. Саволҳои таълимӣ ҳоло дар кадом каналҳо муҳокима мешаванд?
2. Барои нашри савол кадом маълумот ҳатмист?
3. Оё ҳар савол бояд пеш аз нашр аз moderation гузарад?
4. Барои саволи радшуда кадом сабаб бояд ба муаллиф нишон дода шавад?
5. Кӣ метавонад ҷавоби беҳтаринро интихоб кунад ва оё онро иваз кардан мумкин аст?
6. Барои vote қоидаи холдиҳӣ ва маҳдудияти self-vote чӣ гуна аст?
7. Кадом намуд ва ҳаҷми файл барои attachment иҷозат аст?
8. Кадом огоҳиномаҳо муҳиманд ва дар дохили система ё тавассути email фиристода мешаванд?
9. Tag аз category чӣ фарқ дорад ва кӣ tag месозад?
10. Кадом ҳисобот ва сутунҳо барои CSV заруранд?

*Эзоҳ: рӯйхати боло нақшаи ҷамъоварии талабот аст, на гузориши мусоҳибаи анҷомшуда. Пас аз мусоҳиба ҷавобҳо ва қарорҳои тасдиқшуда илова карда шаванд.*
