# Санҷишҳои Day 12

Санҷиш дар PHP built-in server иҷро шуд.

| HTTP request | Expected | Actual |
|---|---:|---:|
| `GET /` | 200 | 200 |
| `GET /questions` | 200 | 200 |
| `GET /questions/1` | 200 | 200 |
| `GET /questions/999` | 404 | 404 |
| `GET /not-a-route` | 404 | 404 |
| `POST /questions` | 405 | 405 |

Илова бар ин, санҷида шуд:

- Header-и `Allow: GET` барои ҷавоби 405 фиристода мешавад.
- Ҷустуҷӯи ҳарфҳои кириллӣ бо фарқи ҳарфи калон/хурд кор мекунад.
- Қимати санҷишии `<b>Test</b>` ҳамчун матни escape-шуда баромад кард, на ҳамчун HTML.
- Ҳамаи файлҳои PHP-и синфҳо ва template-ҳо аз `php -l` гузаштанд.
- `composer.json` ҳамчун JSON дуруст хонда шуд ва PSR-4 mapping-и `App\\` → `src/` тасдиқ шуд.

Эзоҳ: дар муҳити сохтани архив фармони Composer насб набуд. Аз ин рӯ `composer install` дар ин муҳит иҷро нашуд; онро дар компютери худ пеш аз оғоз кардани сервер иҷро кунед. HTTP санҷишҳо бо autoloader-и муваққатии PSR-4 иҷро шуданд; он ба архив дохил карда нашудааст.
