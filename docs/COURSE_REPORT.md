# Ҳисоботи курсӣ: Платформаи саволу ҷавоби донишҷӯён

**Вариант:** 24  
**Номи низом:** Student Q&A  
**Навъи барнома:** барномаи вебии монолитӣ

## 1. Муқаддима

Донишҷӯён ҳангоми омӯзиши фанҳо зуд-зуд ба масъалаҳое дучор мешаванд, ки ҷавоби онҳо дар китоб ё лексия осон ёфт намешавад. Муошират дар гурӯҳҳои паёмрасон донишро пароканда мекунад: саволҳои такрорӣ пайдо мешаванд, ҷавоби дуруст ҷудо намемонад ва таҷрибаи донишҷӯён ба наслҳои дигар намегузарад.

Платформаи Student Q&A ҷойи ягона барои нашр, ҷустуҷӯ ва баррасии саволҳои таълимӣ мебошад. Донишҷӯ метавонад ҷавоб диҳад, ба маводи муфид овоз диҳад ва ҷавоби беҳтаринро интихоб кунад. Модератор муҳтавои нав ва шикоятҳоро мебинад. Маъмур корбарон, бахшҳо, танзимоти платформа ва ҳисоботҳоро идора мекунад.

## 2. Масъала, мақсад ва вазифаҳо

### Масъала

Ҷараёни парокандаи саволу ҷавоб сабти устувор надорад, дарёфти ҷавобро душвор мекунад ва барои пешгирии маводи номуносиб воситаи ягона пешниҳод намекунад.

### Мақсад

Сохтани платформаи вебии бехатар ва дастрас, ки донишҷӯёнро барои мубодилаи дониш муттаҳид мекунад ва кори модератсияро бо сабти таърих дастгирӣ менамояд.

### Вазифаҳо

1. Тарҳрезии пойгоҳи додаи муносибатӣ барои корбарон, саволҳо, ҷавобҳо, овозҳо ва таърихи reputation.
2. Татбиқи воридшавӣ ва ҳуқуқи алоҳида барои се нақш.
3. Сохтани CRUD-и саволу ҷавоб, ҷустуҷӯ ва филтри бахш.
4. Пешниҳоди саволҳои эҳтимолан монанд пеш аз фиристодани саволи нав.
5. Татбиқи овоздиҳӣ, ҷавоби беҳтарин ва ҳисобкунии reputation бо транзаксия.
6. Сохтани навбати модератсия, шикоят, огоҳинома ва содироти CSV.
7. Дастгирии тоҷикӣ, русӣ ва англисӣ ва тартиб додани санҷишу ҳуҷҷат.

## 3. Талаботи низом

### Талаботи функсионалӣ

- Корбар метавонад ҳисоб созад, ворид шавад, барояд ва маълумоти профилро иваз кунад.
- Донишҷӯ саволро бо сарлавҳа, тавсиф, бахш ва замима фиристода, баъд онро таҳрир ё нест карда метавонад.
- Саволи нав аввал дар ҳолати `pending` мемонад; модератор онро тасдиқ ё рад мекунад.
- Корбар саволҳои нашршударо бо ҷустуҷӯ, бахш ва pagination мебинад.
- Донишҷӯ ба саволи нашршуда ҷавоб медиҳад, ҷавоби худро таҳрир ё нест мекунад.
- Муаллифи савол метавонад яке аз ҷавобҳоро ҷавоби беҳтарин интихоб кунад.
- Корбар ба саволу ҷавоби дигарон як овози фаъол мегузорад; овоз ба маводи худ манъ аст.
- Овоз, ҷавоби беҳтарин ва модератсия ба қабулкунанда огоҳинома мефиристанд.
- Модератор навбати саволҳо, шикоятҳо ва таърихи амалиётро мебинад.
- Маъмур корбар, нақш, бахш, саволу ҷавоб ва танзимоти асосиро идора мекунад ва CSV мегирад.
- Замимаи хусусӣ танҳо тавассути роҳи санҷидашудаи дастрасӣ дода мешавад.

### Талаботи ғайрифунксионалӣ

- **Амният:** CSRF, password hash, binding-и параметрҳо тавассути Eloquent, Policy, санҷиши файл ва escape-и Blade.
- **Боваринокӣ:** амалиёти овоз ва reputation дар транзаксия; калиди ягонаи ҳодиса зидди такрори ҳисоб.
- **Самаранокӣ:** pagination, eager loading, индексҳои дода ва ҷустуҷӯи `FULLTEXT` дар MySQL; рӯйхати номзадҳо барои муқоисаи матн маҳдуд аст.
- **Истифодабарӣ:** тарҳи мутобиқ ба андозаи экран, ҳолати холӣ ва паёмҳои муваффақият/хатогӣ.
- **Нигоҳдорӣ:** сохтори Laravel, service барои қоидаҳои такроршаванда, migration ва санҷишҳои автоматӣ.
- **Забон:** интерфейс, паёмҳои асосӣ ва validation бо се забон.

## 4. Технологияҳо

| Технология | Истифода |
| --- | --- |
| PHP 8.5 | забони серверӣ; талаботи Laravel 13 аз 8.3 оғоз мешавад |
| Laravel 13 | routing, middleware, validation, authorization, notification ва lifecycle-и барнома |
| MySQL | нигоҳдории доимии додаҳои истеҳсолӣ; collation-и `utf8mb4` |
| Eloquent ORM | model, relationship, query ва транзаксия |
| Blade | қолабҳои HTML бо escape-и пешфарз |
| Tailwind CSS | тарҳи responsive ва ҷузъҳои интерфейс |
| JavaScript ва Vite | пешниҳод кардани саволҳои монанд ва сохтани asset-ҳо |
| PHPUnit | санҷиши қоидаҳои муҳим ва endpoint-ҳои веб |

## 5. Меъморӣ

Барнома монолит аст: браузер ба веб-сервер муроҷиат мекунад; Laravel дар як барнома route-ро иҷро карда, middleware, controller, service, policy ва Eloquent-ро истифода мебарад. MySQL додаҳоро нигоҳ медорад. Blade натиҷаи HTML месозад. Замимаҳо берун аз директорияи дастрасии мустақими веб нигоҳ дошта мешаванд ва танҳо пас аз санҷиши ҳуқуқ пешниҳод мешаванд.

`Controller` дархостро қабул мекунад ва validation-ро иҷро менамояд. `Policy` ҳуқуқи соҳиби мавод ё нақшро месанҷад. `VotingService`, `ReputationService`, `SimilarQuestionService` ва `PlatformSettingsService` қоидаҳои мушаххаси платформаро нигоҳ медоранд. `Model` робитаи объектҳоро бо ҷадвалҳо муайян мекунад. Сарчашмаи диаграммаи фаъолият раванди воқеии ҳамин татбиқро нишон медиҳад.

## 6. Пойгоҳи дода

Migration-ҳои Laravel дар `database/migrations/` ҷойгиранд. Schema ва seed-и SQL-и пешина нигоҳ дошта шудаанд, аммо migration-ҳои Laravel манбаи сохтори татбиқи ҷорӣ мебошанд.

| Ҷадвал | Мазмун |
| --- | --- |
| `users` | ном, email, password hash, role, status, забони интихобӣ ва reputation-и ҷамъшуда |
| `categories` | номи бахш, slug ва фаъол будан |
| `questions` | муаллиф, бахш, матн, ҳолати нашр, шумораи боздид ва ҷавоби қабулшуда |
| `answers` | ҷавоб, муаллиф, саволи волидайн ва ҳолати намоиш |
| `votes` | овози ягонаи корбар ба `Question` ё `Answer` тавассути polymorphic relation |
| `reputation_transactions` | хол, сабаб, actor, source ва калиди ягонаи ҳодиса |
| `question_attachments`, `answer_attachments` | номи аслӣ, MIME, андоза ва роҳи файли хусусӣ |
| `reports` | шикояткунанда, маводи шикоятшуда, сабаб ва қарори баррасӣ |
| `moderation_logs` | модератор, маводи таъсирдида, амал ва эзоҳ |
| `notifications` | огоҳиномаҳои Laravel бо санаи хондан |
| `platform_settings` | забони пешфарз, бақайдгирӣ ва андозаи замима |
| `sessions`, `cache`, `jobs`, `password_reset_tokens`, `migrations` | ҷадвалҳои Laravel барои инфрасохтори барнома |

Муносибатҳои асосӣ: як корбар бисёр саволу ҷавоб дорад; як бахш бисёр савол дорад; савол бисёр ҷавоб ва замима дорад; савол як ҷавоби қабулшуда дорад; овоз ба савол ё ҷавоб polymorphic аст. Нест кардани савол ҷавобҳо ва файлҳои сабтшударо пок мекунад. Нест кардани бахше, ки савол дорад, маҳдуд аст. Таърихи reputation сабтро нигоҳ медорад, ҳатто вақте ки ҳодисаи овоз баргардонда мешавад; нуқтаи он ба сифр нав карда мешавад.

## 7. Нақшҳо

### Донишҷӯ (`student`)

Метавонад савол гузорад ва онро таҳрир кунад, ба саволҳои нашршуда ҷавоб диҳад, овоз диҳад, ҷавоби беҳтаринро барои саволи худ интихоб кунад ва профилу огоҳиномаҳоро бинад. Муаллиф метавонад танҳо мундариҷаи худашро иваз ё нест кунад.

### Модератор (`moderator`)

Панели ҷудогона дорад. Саволҳои `pending`-ро тасдиқ ё рад мекунад, шикоятҳоро мебинад, маводи номуносибро пинҳон мекунад ва таърихи амалро мебинад. Ҳар қарор ба `moderation_logs` сабт мешавад.

### Маъмур (`admin`)

Панели маъмурӣ омор, корбарон, бахшҳо, саволу ҷавоб, танзимоти асосӣ ва содироти CSV-ро медиҳад. Маъмур инчунин ба навбати модератсия дастрасӣ дорад. Низом паст кардани нақши худи маъмур ва ғайрифаъол кардани маъмури охирини фаъолро манъ мекунад.

## 8. Модулҳои асосӣ

- **Authentication ва профил:** танҳо донишҷӯ аз шакли умумӣ сабт мешавад; password бо cast-и `hashed` нигоҳ дошта мешавад. Воридшавии нодуруст маҳдуд ва session аз нав сохта мешавад.
- **Савол ва ҷавоб:** validation серверӣ, санҷиши соҳиби мавод ва саҳифабандӣ.
- **Ҷустуҷӯи монандӣ:** дар MySQL `FULLTEXT` номзадҳоро маҳдуд мекунад; SQLite дар санҷиш `LIKE`-ро истифода мебарад. Сипас мувофиқати калимаҳо ва унвон ҳисоб шуда, то 5 натиҷаи беҳтарин нишон дода мешавад.
- **Овоз ва reputation:** овози боло барои муаллиф `+10`, овози поён `-2`, интихоби ҷавоби беҳтарин `+15` хол медиҳад. Овози такрорӣ иваз ё бекор мешавад. Овози худӣ иҷозат надорад. Ҳангоми нест кардан ё пинҳон кардани мавод овозҳои ба он вобаста ва холҳои онҳо баргардонда мешаванд. Барои овоз ва ҷавоби қабулшуда event key-и ягона истифода мешавад.
- **Модератсия ва шикоят:** қарор дар як транзаксия бо log сабт шуда, ба муаллиф ё шикояткунанда notification мефиристад.
- **Замима ва огоҳинома:** файлҳои иҷозатдодашуда то 3 адад, андоза аз танзимот то 20 МБ; нигаҳдорӣ бо номи тасодуфӣ ва дастрасӣ тавассути controller.
- **Ҳисобот:** маъмур CSV-и корбар, савол, ҷавоб ё reputation activity мегирад. Майдонҳои ба формула монанд ҳангоми содирот безарар мешаванд.
- **Забон:** `tj`, `ru`, `en` дар `resources/lang/` ва переключатели болоии саҳифа.

## 9. Насб ва танзим

1. PHP 8.3+, Composer 2, Node.js/npm ва MySQL 8 насб кунед; extension-ҳои `pdo_mysql`, `mbstring` ва `fileinfo` фаъол бошанд.
2. Дар MySQL пойгоҳи дода созед:

   ```sql
   CREATE DATABASE student_qa CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. Файли муҳитро нусхабардорӣ карда, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME` ва `DB_PASSWORD`-ро пур кунед:

   ```powershell
   Copy-Item .env.example .env
   ```

4. Вобастагиҳо ва калиди барномаро танзим кунед:

   ```powershell
   composer install
   php artisan key:generate
   npm install
   npm run build
   ```

5. Migration ва Demo account-ҳоро бор кунед:

   ```powershell
   php artisan migrate --seed
   ```

6. Барои рушд:

   ```powershell
   php artisan serve
   ```

   Суроғаи маҳаллӣ одатан `http://127.0.0.1:8000` мебошад. Санҷишҳо: `php artisan test`.

### Ҳисобҳои намоишӣ

Рамзи ҳамаи ин ҳисобҳо `password` аст: `student@example.com`, `peer@example.com`, `moderator@example.com`, `admin@example.com`. Онҳоро танҳо барои санҷиши маҳаллӣ истифода баред.

## 10. Санҷиш

Санҷишҳои feature сабт, нақш, CRUD-и савол ва ҷавоб, маҳдудияти овоз, reputation, ҷавоби беҳтарин, модератсия, монандии савол, танзимот ва ҳуқуқи CSV-ро месанҷанд. Миёнаи санҷиш аз SQLite in-memory истифода мекунад; сохтори migration бо SQLite ва seeder санҷида шудааст. Дар муҳити таҳия MySQL/MariaDB фаъол набуд, бинобар ин санҷиши амалии пайвастшавии MySQL ба сервери соҳиби лоиҳа мондааст. Санҷишҳои охирин: **14 санҷиш, 14 гузашт, 73 assertion**.

Рӯйхати 20 санҷиши дастӣ дар `docs/MANUAL_TESTING.md` ҷойгир аст. Натиҷаи санҷиши истеҳсолӣ бояд пас аз ворид кардани маълумоти воқеии сервер илова карда шавад.

## 11. Дастури корбар

1. Забони интерфейсро аз рӯйхати боло интихоб кунед.
2. Бо email сабт шавед ё ба Demo account ворид шавед.
3. Аз рӯйи бахш ё калима саволи нашршударо ҷустуҷӯ кунед.
4. Барои саволи нав сарлавҳа ва тавсиф нависед; пешниҳодҳои саволи монандро бинед; агар лозим шавад идома диҳед. Савол пас аз фиристодан дар навбати модератор мемонад.
5. Ба саволи нашршуда ҷавоб диҳед ва замима илова кунед.
6. Барои муфид будани савол ё ҷавоб овоз диҳед. Овози такрорӣ онро бекор мекунад; овоз ба мундариҷаи худ манъ аст.
7. Агар саволро худатон гузошта бошед, метавонед ҷавоби беҳтаринро интихоб кунед.
8. Огоҳиномаҳо ва таърихи reputation-ро дар панели донишҷӯ бинед.
9. Барои мундариҷаи номуносиб тугмаи шикоятро истифода баред.

## 12. Нашр ва хулоса

Барои сервер, директорияи document root бояд ба `public/` ишора кунад. Ба корбар иҷозати навиштан ба `storage/` ва `bootstrap/cache/` диҳед; `.env`, `vendor/` ва файли шахсии замимаҳоро аз веб пинҳон нигоҳ доред. Пеш аз нашр `APP_ENV=production`, `APP_DEBUG=false`, калиди махсус, маълумоти воқеии MySQL ва HTTPS-ро танзим кунед. Баъд `composer install --no-dev --optimize-autoloader`, `npm ci`, `npm run build`, `php artisan migrate --force`, `php artisan config:cache`, `php artisan route:cache` ва `php artisan view:cache` иҷро кунед. Барои баргардонидан нусхаи эҳтиётии MySQL ва `storage/app/private` нигоҳ доред.

Натиҷаи кор як заминаи Laravel-и коршоям бо authentication, идоракунии нақшҳо, саволу ҷавоб, reputation, модератсия, notification, се забон, замима ва CSV мебошад. Санҷишҳои автоматӣ қоидаҳои асосиро тасдиқ карданд. Қадами охирин барои ҷойгиркунии воқеӣ санҷиши MySQL ва танзими HTTPS-и сервери мақсаднок аст.
